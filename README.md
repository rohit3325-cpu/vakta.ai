# Vakta AI – AI Mock Interview System

Vakta AI is an AI-powered mock interview platform built to help students and job seekers prepare for technical and HR interviews through realistic AI-driven conversations. The platform provides voice-based interaction, intelligent feedback, and an interactive interview experience.

---

## 🚀 Features

- 🤖 AI-powered mock interviews
- 🎤 Real-time voice interaction using Vapi
- 💬 Dynamic interview question generation
- 🧠 Gemini AI integration for smart responses
- 📊 Interview feedback and evaluation
- 🔐 Secure authentication with Firebase
- 🌐 Fully responsive modern UI
- ⚡ Fast and scalable architecture

---

## 🛠️ Tech Stack

### Frontend
- Next.js
- Tailwind CSS
- Framer Motion

### Backend & Database
- Firebase
- Firestore Database

### AI & APIs
- Gemini API
- Vapi AI

⚙️ Installation
Clone the repository:
Bash
git clone https://github.com/rohit3325-cpu/vakta.ai.git
Move into the project directory:
Bash
cd vakta.ai
Install dependencies:
Bash
npm install
Start the development server:
Bash
npm run dev
🔑 Environment Variables
Create a .env.local file in the root directory and add:
Environment
NEXT_PUBLIC_FIREBASE_API_KEY=your_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_domain
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id

GEMINI_API_KEY=your_gemini_api_key
VAPI_API_KEY=your_vapi_api_key
